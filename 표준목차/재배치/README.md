# 재배치 — 표준 목차로 문항을 옮긴 기록

## 왜 「어긋남 %」를 버렸나

처음에 「한 절이 여러 편에 걸친 문항」을 어긋남으로 셌다. **그 잣대가 틀렸다.**

| 잣대 | 잡힌 수 | 실제 |
|---|---:|---|
| 절 이름이 여러 편에 걸침 | 240문항 | 대부분 정상 |
| 두루 쓰는 이름(총칙·용어의 정의…) 제외 | 97 | 여전히 대부분 정상 |
| **문항 지문을 읽고 판정** | **손에 꼽음** | 이것만 맞다 |

- 「총칙」은 지방세기본법에도 지방세법에도 있는 정당한 장이다 → 지방세법 12%는 허수
- 「용어의 정의」는 모든 법률에 다 있다 → 주택관리관계법규 9%도 허수
- 「부당행위계산부인」은 법인세법·소득세법 둘 다에 있다
- 소방의 「화재예방강화지구」는 **법이 실제로 옮겨 갔다**(2022년 화재예방법 제정) —
  옛 문항이 소방기본법, 새 문항이 화재예방법에 있는 것이 출제 당시 법에 맞다

**기계가 셀 수 있는 잣대는 틀렸고, 지문을 읽는 잣대만 맞았다.**

## 그래서 무엇을 고치나

진짜 병은 어긋남이 아니라 **목차가 문항을 고르게 못 나누는 것**이다.

1. **뭉침** — 절 하나에 25문항 넘게 몰린 자리. 눌러도 수십 문항이 쏟아진다
2. **빠진 장** — 3사 만장일치인데 앱에 없는 장

## 어떻게 가르나

절을 새로 만들 때 **표준 목차에 있는 절 이름만 쓴다.** 지어내지 않는다.
문항이 어느 절인지는 **지문이 무엇을 묻는지**로 정하고, 규칙으로 안 갈리는 것은
하나씩 읽어 손으로 정한다. 그 목록도 남긴다.
