# 봄기출 표준 목차 — 주택관리사 「민법」
원본 `원본/주택관리사/민법-3사.md` · 기출 240문항

**공인중개사 민법과 범위가 다르다** — 주택관리사 민법은 **채권법까지** 들어간다.

## 편 — 3편 (2:1)
| | 편 |
|---|---|
| 박문각 | **3편** 민법총칙 / 물권법 / 채권법 |
| 에듀윌 | 5편 (통칙 / 주체와 객체 / 권리의 변동 / 물권법 / 채권법) |
| 해커스 | 4편 (민법총칙 / 물권법 / 채권총론 / 채권각론) |

- 총칙을 하나로 두는 것 **2:1**(박문각·해커스) — 에듀윌만 셋으로 쪼갠다
- 채권법을 하나로 두는 것 **2:1**(박문각·에듀윌) — 해커스만 총론/각론으로 나눈다
→ **3편.** 앱도 3편(민법총칙/물권법/채권법) — 일치.

## 장 — 「권리의 주체」에 42문항이 뭉쳤다 (규칙 2)
앱 민법총칙 9장 중 「권리의 주체」가 **42문항**이다. 3사는 이렇게 가른다.
| | 박문각 | 에듀윌 | 해커스 |
|---|---|---|---|
| 자연인 | Chapter 02 | CH01 | 제3장 제2절 |
| 법인 | Chapter 03 | CH02 | 제3장 제3절 |
박문각·에듀윌이 **자연인·법인을 다른 장**으로 둔다(2:1). 갈라야 한다.
