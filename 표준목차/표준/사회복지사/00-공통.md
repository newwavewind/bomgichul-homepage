# 사회복지사 1급 8과목 — 표준을 세우는 방식

원본 `원본/사회복지사/8과목-3사.md`

## 세 곳이 층이 다르다

| | 층 | 장 수 |
|---|---|---|
| 나눔의집 | 장만 (편 없음) | 11~14 |
| 해커스 | 영역 → 장 | 3~5 |
| 에듀윌 | 영역 → 장 | 5~7 |

**나눔의집이 가장 잘고 해커스가 가장 굵다.** 그런데 셋의 갈래는 어긋나지 않는다 —
해커스의 한 장이 나눔의집의 서너 장을 묶은 것이다. 예를 들어 지역사회복지론에서

```
해커스 제1장 「실천의 토대」  =  나눔의집 1·2장 (개념과 유형 + 지역사회복지실천)
해커스 제2장 「이론과 모델」  =  나눔의집 4·5장 (주요 이론 + 실천모델)
해커스 제3장 「과정과 기술」  =  나눔의집 6·7·8·9장 (과정 + 역할 + 기술Ⅰ·Ⅱ)
해커스 제4장 「실재」       =  나눔의집 3·10·11·12·13장 (역사 + 보장계획 + 추진체계 + 운동)
```

## 그래서 이렇게 정한다

- **편**은 해커스·에듀윌의 굵은 갈래(3~5개)를 쓴다. 과목당 250문항이므로
  편이 4~6개여야 편마다 40~60문항이 된다(규칙 2).
- **장**은 나눔의집의 잘은 갈래를 쓴다. 장마다 15~25문항이 된다.
- **절**은 3사 목차에서 얻을 수 없다 — 셋 다 절을 싣지 않는다.
  그래서 절은 **기출 문항이 실제로 묻는 주제**로 세운다. 이것은 「자동 생성」이 아니라
  기출을 읽고 세우는 일이며, 편·장이라는 자를 이미 3사로 잡아 두었으므로 흘러가지 않는다.

## 이 앱만 왜 심한가

기출 2,000문항 중 **1,582문항(79%)** 의 편이 절과 어긋나 있다. 우연히 맞을 확률(25%)과
거의 같아 값이 없는 것과 같다. 다른 네 앱은 0~12%다. **여기는 갈아엎는다.**
