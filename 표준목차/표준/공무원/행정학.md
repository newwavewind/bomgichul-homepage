## 1. 표준 목차

### 제1편 행정학총론 (앱 68문항)

- **제1장 행정의 의의** — 정치·행정 이원론과 일원론 / 행정의 개념과 행정·경영·정치 ☆
- **제2장 현대행정의 이해** — 시장실패와 정부실패 / 정부규제 / 규제정치의 유형 / 정책수단 / 정부관과 정부조직
- **제3장 공공서비스 공급주체** — 공기업과 민영화 / 책임운영기관 / 민간위탁과 민간투자 / 민원행정
- **제4장 행정학의 접근방법** — 과학적 관리론과 인간관계론 / 공공선택이론 / 신제도주의
- **제5장 행정학의 주요이론** — 신행정학 / 신공공관리론 / 거버넌스와 신공공서비스론 / 공공가치론 / 행정이론의 전개
- **제6장 행정이 추구하는 가치** — 공익 / 사회적 형평성과 정의 / 행정가치의 체계

### 제2편 정책학 (74문항)

- **제1장 정책학의 의의** — 정책학의 발달 / 로위의 정책유형 / 리플리와 프랭클린의 정책유형
- **제2장 정책과정의 주도자** — 정책참여자 / 엘리트론과 다원론 / 정책네트워크와 철의 삼각 / 정책옹호연합모형
- **제3장 정책의제론** — 정책의제설정 모형 / 무의사결정론 / 정책흐름모형
- **제4장 정책분석론** — 정책문제의 구조화 / 미래예측기법 / 비용·편익분석 / 정책분석의 기준
- **제5장 정책결정론** — 정책환경의 불확실성
- **제6장 정책결정모형** — 합리모형과 만족모형 / 점증모형과 혼합주사모형 / 앨리슨 모형 / 쓰레기통모형과 사이버네틱스 / 조직의 의사결정

- **제8장 정책평가론** — 정책평가의 유형과 논리모형 / 내적 타당성 / 외적 타당성과 신뢰성 / 사회실험과 정책변수 / 정책변동

### 제3편 조직이론 (63문항)

- **제1장 조직이론의 기초** — 조직이론의 전개 / 거시조직이론 / 조직목표

### 제4편 인사행정론 (75문항)

- **제1장 재무행정의 기초** — 예산의 원칙 / 예산의 종류와 분류 / 재정의 기능과 공공재원 / 통합재정 / 정부회계

## 2. 세 곳이 갈린 곳과 판단

### (1) 편은 일곱, 순서는 「환류 → 지방」

| 순서 | 해커스 | 박문각 | 에듀윌 |
|---|---|---|---|
| 1 | 행정학의 기초이론 | 행정학총론 | 행정학 총론 |
| 2 | 정책학 | 정책학 | 정책학 |
| 3 | 조직이론 | 조직론 | 조직이론 |
| 4 | 인사행정론 | 인사행정 | 인사행정론 |
| 5 | 재무행정론 | 재무행정 | 재무행정론 |
| 6 | **지방자치론** | **행정환류** | **행정환류론** |
| 7 | **행정의 환류** | **지방자치론** | **지방행정론** |
| 8 | — | 기타 제도 및 법령 등 | — |

- 여섯 덩어리(총론·정책·조직·인사·재무·환류·지방)는 세 곳이 똑같다. **7편으로 세운다.**
- 6·7편 순서는 박문각·에듀윌이 「환류 → 지방」 **2표**. 그쪽으로 정한다.
- 박문각 제8편 「기타 제도 및 법령 등」은 앞 일곱 편을 법령으로 되짚는 마무리 정리(Day 28~30)라
  독립 편으로 세우지 않는다. 한 곳만 가진 편이기도 하다.
- 편 이름 「지방자치론」은 해커스·박문각 **2표**, 「지방행정론」은 에듀윌 1표. 다수결로 지방자치론.

### (2) 총론에서 「공공서비스 공급주체」를 어디 두나

- 에듀윌: 총론 제3장으로 세운다.
- 박문각: 총론 Chapter 05 「행정과 환경」(정부와 시장 / 정부와 시민사회) 안.
- 해커스: 조직이론 제13장 제3절 「공기업과 책임운영기관」으로 내려보낸다.

→ **총론에 두는 쪽이 2표**(에듀윌·박문각). 장으로 세우는 건 에듀윌 1표뿐이지만, 앱에 공기업·민영화·
책임운영기관·민간위탁·민원행정 다섯 절 분량이 있어 절로 눌러 두면 다른 장이 지나치게 커진다.
장으로 세우고 자리는 에듀윌을 따라 **현대행정의 이해 바로 뒤(제3장)** 로 옮긴다. 정부실패 → 민영화로
읽히는 자리다.

### (3) 접근방법과 주요이론을 하나로 묶나 둘로 가르나

- 해커스 제3장 「행정학의 접근 방법」 한 장 / 박문각 Chapter 02 「행정이론」 한 장 → **한 장이 2표**
- 에듀윌만 「행정학의 접근방법」 + 「행정학의 주요이론」 둘로 가른다.

→ **에듀윌(소수)을 따랐다.** 근거를 적는다. 합치면 절이 여덟(과학적 관리론과 인간관계론 / 공공선택이론 /
신제도주의 / 신행정학 / 신공공관리론 / 거버넌스와 신공공서비스론 / 공공가치론 / 행정이론의 전개)이
되어 한 장에 몰린다. 규칙 2(한 자리에 몰리면 가른다)가 다수결보다 앞선다.

### (4) 전자정부를 어디 두나 — 세 곳이 다 다르다

- 해커스: 제7편 행정의 환류, **제32장 「지식정보사회와 전자정부」**
- 에듀윌: 조직이론 **CHAPTER 09 「정보체계론」**
- 박문각: Part 1 Chapter 05 「행정과 환경」 **Section 04 전자정부**

→ 자리는 갈리지만 **「장으로 세운다」는 해커스·에듀윌 2표**다. 앱은 「행정환류론 제3장 행정개혁」의
절로 눌러 놨다. 해커스 자리(환류편)를 골랐다. 앱 환류편이 21문항으로 가장 작아 장 하나를 더 받을 여유가
있고, 정부업무평가·BSC 와 성격이 달라 같은 장에 있을 이유가 없다.

### (5) 행정책임과 행정통제 — 한 장인가 두 장인가

- 해커스 제30장 「행정책임과 통제」 / 박문각 Chapter 01 「행정책임과 통제」 → **한 장이 2표**
- 에듀윌만 CHAPTER 01 행정책임 / CHAPTER 02 행정통제로 가른다.

→ 다수결대로 **한 장으로 합친다.** 앱의 「제1장 행정책임」은 절이 「행정책임의 유형」 하나뿐이라
장 층이 헛돈다. 합치면 3절이 되어 모양도 맞는다.

### (6) 조달행정·정부계약

- 해커스 제25장 「조달행정과 정부계약」 / 박문각 Chapter 08 「재무행정기관, 그리고 정부기관의 구매」
  → **2표로 독립 장**
- 에듀윌에는 없다.

→ 2표지만 **장이 아니라 절로 넣었다.** 앱 400문항 안에 조달·정부계약을 정면으로 묻는 문항이 지금은
없다. 빈 장을 세우면 눌렀을 때 아무것도 안 나오는 칸이 된다. 예산개혁론 아래 절로 자리만 만들어 두고,
문항이 붙으면 장으로 올린다.

### (7) 기획론

해커스만 제10장 「기획론」을 둔다(1표). 박문각·에듀윌에 없고 앱 문항도 없다. **세우지 않는다.**

- 조직이론 제8장 조직개혁론에 절이 「총체적 품질관리(TQM)」 하나뿐이다. 절 하나짜리 장이다.
  세 곳 다 조직개혁·조직혁신을 장으로 두므로 장은 살리고, 「조직혁신과 조직발전」 절을 더한다.

### ③ 장을 합칠 것 (1개)

- 행정환류론 **제1장 행정책임 + 제2장 행정통제 → 「제1장 행정책임과 통제」**. (해커스·박문각 2표)

### ④ 장 차례·이름

- 행정학총론: 「공공서비스 공급주체」를 제6장 → **제3장**으로 (에듀윌).
- 조직이론: 「조직의 유형」을 제4장 → **제2장**으로, 「조직구조론」을 제2장 → 제3장으로 (에듀윌).
- 지방자치론 제1장 「지방자치의 의의」 → **「지방자치의 기초」**. 세 곳 다 첫 장이 「기초(기초이론)」다.
- 편 이름 「지방행정론」 → **「지방자치론」** (다수결). 다만 안에 지방재정·정부간관계까지 들어 있어
  뜻이 좁아지지도 않는다. **우선순위 낮음** — 편 차례를 고칠 때 같이 손보면 된다.

### ⑤ 절이 문항 수만큼 잘다 — 16개를 합친다

앱 133절 가운데 **문항 1개짜리가 16절, 2개 이하가 52절**이다. 3사 절 수(해커스 94 · 박문각 130)와
견주면 133은 위쪽 끝이다. 문항 1개짜리를 이웃과 합쳐 **약 117절**로 줄인다.
