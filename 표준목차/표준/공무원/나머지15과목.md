# 봄기출 표준 목차 — 공무원 나머지 15과목
원본 `원본/공무원/나머지과목-원본.md`

## 편이 3사와 맞는 과목 (그대로 둔다)

### 국제법개론 (180문항 · 어긋남 0%)
앱 7편 = 해커스 패권 6편 + 「국제경제법」.
해커스는 국제경제법을 별권으로 낸다 → 앱이 한 편으로 둔 것이 맞다. **손볼 곳 없음.**

### 소방학개론 (200문항 · 어긋남 0%)
| 앱 | 정상 소방학개론 |
|---|---|
| 연소이론 49 / 화재이론 24 / 소화이론 24 / 소방시설 30 / 위험물 23 / 소방조직·역사 26 / 재난관리 24 | PART 01~07 그대로 |
**한 자리도 어긋나지 않는다.**

### 소방관계법규 (200문항 · 어긋남 10%)
편이 곧 법률이고 앱 6편 = 박문각 6편(소방기본법 / 화재조사법 / 소방시설법 /
화재예방법 / 소방시설공사업법 / 위험물안전관리법). **21문항만 제자리로.**

### 세법개론 (200문항 · 어긋남 5%)
앱 7편 = 해커스 이훈엽 7편. 다만 앱의 「재산세제(8)」는 해커스의 「상속세 및 증여세법」이다.
**이름을 맞추고 10문항을 제자리로.**

### 노동법개론 (180문항 · 어긋남 0%)
앱은 9편(취업규칙·인사 / 총론·적용 / 근로계약·임금 …), 기본서는 4편(총칙 / 근로기준법 /
노동조합법 / 최저임금법). **기본서 4편으로 가면 근로기준법에 100문항 넘게 뭉친다**(규칙 2)
→ 앱의 9편을 살리되 **「기타 노동법 25문항」을 최저임금법·산업안전 등으로 가른다.**

### 교육학개론 (400문항 · 어긋남 3%)
앱 11편 = 강서연 10장 + 「한국교육사/서양교육사」를 나눈 것.
강서연은 「교육철학 및 교육사」 한 장인데 앱은 교육철학 21 / 한국교육사 22 / 서양교육사 17로 나눈다.
규칙 2가 반대로 걸리나(각 20문항 안팎) **이미 나뉜 것을 되돌릴 실익이 없다** → 그대로.
**11문항만 제자리로.**

### 형법 (200문항 · 어긋남 0%) · 형사소송법 / 형사소송법개론 (각 200문항 · 0%)
경찰 형사법 원본을 함께 쓴다. 앱의 형법 4편(총론 / 개인적·사회적·국가적 법익)은
3사 만장일치와 같다. 형사소송법 10편도 표준 교재 편제와 맞는다. **손볼 곳 없음.**
다만 형법총론 134문항이 한 편에 뭉치므로 **서론 / 범죄론 / 형벌론**으로 가른다(3사 만장일치).

### 회계학 (400문항 · 0%) · 회계원리 (200문항 · 0%)
회계학 앱 3편(재무회계 273 / 원가관리회계 85 / 정부회계 42) — 해커스가 원가·정부를
한 권, 재무를 별권으로 낸다. **편은 맞다.** 다만 재무회계 273문항이 한 편에 뭉치므로
주택관리사 회계원리 표준의 14장을 그대로 쓴다(규칙 2).
회계원리 앱 2편(재무회계 164 / 회계의 순환과정 36)도 같은 처리.

### 교정학개론 (200문항 · 0%)
앱 3편(교정학 총론 53 / 수용자의 처우 107 / 사회 내 처우와 소년사법 40) vs
해커스 이언담 5편. **해커스 5편이 「수용자의 처우 107문항」을 가른다** → 규칙 2로 해커스를 따른다.
| 표준 편 | 해커스 |
|---|---|
| 1 교정학 총론과 형벌이념 | 제1편 1~3장 + 제4편 |
| 2 수용자 공통처우 | 제1편 4~14장 |
| 3 수용자별 처우 | 제2편 |
| 4 수형자의 처우 | 제3편 |
| 5 교정 관련 법령 | 제5편 |

### 사회복지학개론 (400문항 · 5%)
앱 8편 vs 해커스 박정훈 4편. 해커스는 「사회복지방법」에 5개 과목을 몰아넣어
200문항 넘게 뭉친다 → **앱의 8편이 맞다**(규칙 2). **19문항만 제자리로.**
다만 **절이 221개(문항당 1.8)** 로 지나치게 잘다 — 사회복지사 1급 8과목 표준의
장 이름으로 묶는다.

### 지방세법 (200문항 · 어긋남 12% — 공무원 중 가장 심하다)
앱 4편(지방세법 115 / 지방세기본법 54 / 지방세특례제한법 16 / 지방세징수법 15).
편이 곧 법률이라 갈래는 맞으나 **「지방세법 115문항」이 한 편에 뭉친다.**
지방세법은 취득세·등록면허세·재산세·지방소득세·주민세 등 세목이 장이 되어야 한다
(공인중개사 부동산세법 표준의 지방세 편과 같은 처리).
**최신 기본서를 못 찾았다** — 구판(2018)만 잡힌다. 세목 구분은 지방세법 법조문 편제를 따른다.

### 관세법개론 (200문항 · 0%)
앱 11편이 **관세법 법조문의 장 편제와 그대로 같다**(총칙 / 세율 및 품목분류 /
과세가격과 부과·징수 / 감면·환급 / 납세자의 권리 및 불복 / 운송수단 / 보세구역 /
운송 / 통관 / 벌칙 / 보칙). **시중 기본서를 못 찾았으나 법령 편제가 자를 대신한다.**
손볼 곳 없음.
