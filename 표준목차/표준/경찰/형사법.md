## 편 — 형법총론 3편 만장일치 + 각론 3편 만장일치 + 형사소송법
형법총론의 편은 **서론(기초) / 범죄론 / 형벌론** 으로 셋이 같다.
죄수론을 범죄론에 넣는 것 2:1(갓대환·허정), 신광은만 형벌론과 묶는다.

## 고칠 자리 — 형법총론 146문항이 한 편에 뭉쳐 있다 (규칙 2)
앱은 형법총론을 18장으로 잘게 나눴으나 **편이 하나**다. 3사대로 3편으로 가른다.

## 봄기출 표준 — 10편
```
1편 형법총론 - 서론
   01 형법의 기본개념      의의와 성격 / 기능
   02 죄형법정주의        의의 / 성격(법률주의·소급효금지·명확성·유추해석금지·적정성)
   03 형법의 적용범위      시간적 / 장소적 / 인적 / 외국에서 받은 형집행의 효력
2편 형법총론 - 범죄론
   04 범죄의 기본개념      범죄의 의의와 종류(계속범·상태범·즉시범) / 주체와 객체 / 법인의 형사책임
   05 구성요건론          일반이론 / 결과·행위반가치 / 인과관계와 객관적 귀속 / 고의 / 사실의 착오
   06 특수한 범죄유형      부작위범 / 과실범 / 결과적 가중범
   07 위법성론           일반이론 / 정당방위 / 긴급피난 / 자구행위 / 피해자의 승낙 / 정당행위(사회상규)
   08 책임론            책임능력(심신장애·원인에서 자유로운 행위) / 위법성의 인식 / 법률의 착오 / 기대가능성
   09 미수론            범죄의 실현단계 / 장애미수 / 중지미수 / 불능미수 / 예비·음모
   10 공범론            공범이론 / 합동범과 동시범 / 간접정범 / 공동정범 / 교사범 / 종범 / 공범과 신분
   11 죄수론            일죄와 수죄(법조경합·상상적경합·실체적경합·포괄일죄) / 수죄의 처벌
3편 형법총론 - 형벌론
   12 형벌              형벌의 종류 / 형의 양정 / 누범 / 선고유예·집행유예·가석방 / 시효와 소멸 / 몰수·추징
   13 보안처분
4편 형법각론 - 개인적 법익
   14 생명과 신체        살인 / 상해와 폭행 / 과실치사상 / 낙태 / 유기와 학대
   15 자유              협박 / 체포와 감금 / 약취·유인 및 인신매매 / 강요 / 강간과 추행
   16 명예·신용 및 업무   명예훼손 / 신용·업무방해·경매입찰방해
   17 사생활의 평온      비밀침해 / 주거침입
   18 재산              일반론 / 절도 / 강도 / 사기 / 공갈 / 횡령 / 배임 / 장물 / 손괴 / 권리행사방해
5편 형법각론 - 사회적 법익
   19 공공의 안전과 평온   공안 / 폭발물 / 방화와 실화 / 일수와 수리 / 교통방해
   20 공공의 신용        통화 / 유가증권·우표·인지 / 문서 / 인장
   21 공중의 건강과 사회의 도덕  먹는 물 / 아편 / 성풍속 / 도박과 복표 / 신앙
6편 형법각론 - 국가적 법익
   22 국가의 존립과 권위   내란 / 외환 / 국기 / 국교
   23 국가의 기능        공무원의 직무(뇌물·직권남용) / 공무방해 / 도주와 범인은닉 /
                       위증과 증거인멸 / 무고
7편 형사소송법 - 소송의 주체
   24 법원·검사·피고인    관할 / 제척·기피·회피
   25 변호인            선임 / 접견교통권
8편 형사소송법 - 수사
   26 수사의 단서        고소·고발 / 불심검문 / 함정수사
   27 임의수사          피의자신문 / 참고인조사
   28 수사의 종결        수사준칙 / 검·경 협력
9편 형사소송법 - 강제처분
   29 체포              영장에 의한 체포 / 긴급체포 / 현행범체포
   30 구속              요건과 절차 / 구속기간 / 구속적부심
   31 압수·수색·검증     영장주의 / 영장 없는 압수·수색 / 전자정보
   32 그 밖의 강제처분    증거보전 / 통신제한조치
10편 형사소송법 - 증거
   33 증거재판주의와 증명   거증책임 / 자유심증주의
   34 자백배제법칙과 자백보강법칙
   35 위법수집증거배제법칙
   36 전문법칙          전문법칙의 예외 / 조서의 증거능력
   37 동의와 탄핵증거
```
**고칠 것**
1. 형법총론을 **3편으로 가르기** (3사 만장일치)
2. **「형사절차 종합(사례형 14문항)」을 없애기** — 3사 어디에도 없다. 사례형은 편이 아니라
   문제 형식이므로, 각 문항이 실제로 묻는 자리(수사·증거 등)로 옮긴다.
