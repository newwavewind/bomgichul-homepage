## 봄기출 표준 — 2편 10장
```
1편 공간정보의 구축 및 관리 등에 관한 법률 (120문항)
   01 총칙            지적제도와 등기제도의 개관 / 법의 목적과 기본이념 / 용어의 정의 /
                     지적제도의 분류 / 지적제도와 등기제도의 비교
   02 토지의 등록       토지의 조사 및 등록 / 토지의 등록단위(필지) / 지번 / 지목 / 경계 / 면적
   03 지적공부         지적공부의 의의 / 토지대장 / 공유지연명부 / 대지권등록부 / 도면 /
                     경계점좌표등록부 / 보존·반출·공개 / 복구 / 부동산종합공부 / 지적전산자료
   04 토지의 이동과 지적정리 신규등록 / 등록전환 / 분할 / 합병 / 지목변경 / 바다로 된 토지의 등록말소 /
                     등록사항의 정정 / 축척변경 / 토지이동의 신청 및 신고 / 지적정리·소유자정리·통지
   05 지적측량         지적측량의 의의 / 종류 / 절차 / 적부심사 / 중앙지적위원회와 축척변경위원회
2편 부동산등기법 (120문항)
   06 등기제도 총칙      부동산등기제도 / 등기사항 / 등기의 효력 / 등기의 유효요건
   07 등기기관과 설비     등기소 / 등기관 / 등기기록의 구성 / 구분건물의 등기기록 /
                     등기사항증명서의 열람 및 발급 / 장부의 보존·관리
   08 등기절차 총론      신청주의와 그 예외 / 등기의 당사자능력 / 공동신청 / 단독신청 / 대위신청 /
                     등기신청정보와 첨부정보 / 접수와 심사 / 각하사유 / 등기완료 후의 절차 /
                     등기관의 처분에 대한 이의신청
   09 표시에 관한 등기    토지의 표시에 관한 등기 / 건물의 표시에 관한 등기
   10 권리에 관한 등기    소유권보존등기 / 소유권이전등기(매매·환매특약·수용·진정명의회복·상속·유증·신탁) /
                     공동소유에 관한 등기 / 용익권(지상권·지역권·전세권·임차권) / 담보권(저당권) /
                     변경·경정·말소·말소회복·멸실등기 / 부기등기 / 가등기 / 처분제한등기
```
