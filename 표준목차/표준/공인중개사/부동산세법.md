# 봄기출 표준 목차 — 「부동산세법」
원본 `원본/공인중개사/부동산세법-3사.md` · 기출 160문항

## 편 — 3편, 3사 만장일치
조세총론 / 지방세 / 국세. **앱도 3편 — 일치.**

## 장 — 조세총론만 갈린다
| | 박문각 | 에듀윌 | 해커스 | 판정 |
|---|---|---|---|---|
| 조세총론 장 수 | 2 | 4 | 4 | **2:1로 4장** |

다만 조세총론은 기출이 **17문항**뿐이라 규칙 2(실익)가 반대로 걸린다 —
4장으로 쪼개면 장마다 4문항이 된다. **1장으로 두되 절을 3사대로 갖춘다.**
(규칙 2는 「뭉치면 쪼갠다」이지 「적은데 쪼갠다」가 아니다)

| 지방세·국세의 장 | 3사 |
|---|---|
| 취득세 / 등록면허세 / 재산세 | 만장일치 |
| 기타 지방세 | 해커스만 (앱에 2문항 — 둔다) |
| 종합부동산세 / 소득세 총설 / 양도소득세 | 만장일치 (둘째 장 이름만 「소득세 총론·종합소득세·소득세 총설」로 갈림 → **소득세 총설**, 해커스) |

## 봄기출 표준 — 3편 8장
```
1편 조세총론 (17문항)
   01 조세총론   조세의 개념과 분류 / 조세 관련 용어 / 납세의무의 성립·확정·소멸 /
                납세의무의 확장 / 가산세 / 조세와 다른 채권의 관계(조세우선권과 그 예외) /
                조세의 불복제도 / 서류의 송달
2편 지방세 (68문항)
   02 취득세     취득세의 개요와 취득의 개념 / 과세대상 / 납세의무자 / 취득시기 /
                과세표준 / 세율 / 비과세 / 부과·징수(납세절차)
   03 등록면허세   의의 및 특징 / 납세의무자 / 과세표준 / 세율 / 비과세 / 납세절차
   04 재산세     개요와 과세대상 / 토지에 대한 과세대상 구분 / 납세의무자 / 과세표준 /
                세율 / 비과세 / 부과·징수
   05 기타 지방세  지역자원시설세 / 지방소득세
3편 국세 (75문항)
   06 종합부동산세  의의와 용어정의 / 과세대상 / 납세의무자 / 주택에 대한 과세 /
                토지에 대한 과세 / 비과세 / 신고·납부(납세절차)
   07 소득세 총설  소득세의 개요 / 부동산임대소득 / 부동산업
   08 양도소득세   의의와 과세대상 / 양도의 개념과 형태 / 양도 또는 취득시기 / 비과세 /
                양도소득과세표준의 계산(양도차익·필요경비·장기보유특별공제) /
                양도소득금액 계산의 특례 / 세율 / 비사업용 토지 / 미등기양도자산 /
                면제와 경감 / 신고와 납부 / 국외자산 양도
```
**앱과 견준 결과**: 편 일치, 장 일치. 어긋남 0%. **손볼 곳 없음.**
