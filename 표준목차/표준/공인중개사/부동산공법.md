## 편 — 6편, 3사 만장일치
국토계획법 / 도시개발법 / 도시정비법 / 건축법 / 주택법 / 농지법.
편이 곧 법률이라 이견이 있을 수 없다. **앱도 6편 — 일치.**

## 장 — 앱에 빠지거나 어긋난 자리

### ① 국토계획법에 세 장이 없다
| 장 | 박문각 | 에듀윌 | 해커스 | 앱 |
|---|:--:|:--:|:--:|:--:|
| 총칙(용어의 정의) | ✓ | ✓ | ✓ | **✗** |
| 도시·군기본계획 | ✓ | ✓ | ✓ | **✗** |
| 보칙 및 벌칙 | ✓ | ✓ | ✓ | **✗** |
3사 만장일치인데 앱에만 없다.

### ② 앱의 「시가화·건폐율·용적률」 장은 3사에 없다
그 안에 **토지거래허가**가 들어 있다. 토지거래허가는 국토계획법이 아니라
**「부동산 거래신고 등에 관한 법률」** 소관이고, 3사 모두 공인중개사법령 과목에서 다룬다.
→ 이 절은 과목을 잘못 찾아온 것. 건폐율·용적률은 **용도지역** 장으로 옮긴다.

### ③ 30문항 넘게 뭉친 장 셋 (규칙 2)
| 앱의 장 | 문항 | 3사는 |
|---|---:|---|
| 건축허가 | 39 | 건축허가 / 건축절차 / 대지와 도로 / 용도변경 을 **다른 장**으로 |
| 주택건설사업·조합 | 46 | 주택건설사업자 / 주택조합 / 사업계획승인 / 감리·사용검사 / **리모델링은 별도 장** |
| 기본계획·정비구역 · 정비사업 시행 | 각 30 | 그대로 두되 절을 3사대로 |
