# 봄기출 표준 목차 — 공인중개사 「민법 및 민사특별법」

2026-10-21 다시 세움. 기출 400문항(2016~2025, 41~80번).

## 무엇을 맞대었나

- **기본서 여섯 곳**(YES24 2026판, 2026-10-21 수집) — 원본 `원본/공인중개사/2026-yes24/민법-{박문각,에듀윌,해커스,랜드하나,경록,위패스}.md`.
  경록은 장까지만 있고, 박문각은 민사특별법에 절이 없다.
- **법령 편제** — `ox-admin-quiz-app` 의 `scripts/verify/law-outline.mjs` 는 이 작업 환경에서 법제처로 나가는
  요청이 막혀(응답이 JSON 이 아니라 HTML 오류 쪽) **돌리지 못했다.** 대신 앱이 법제처 OPEN API 로 받아 둔
  조문 표제(`src/data/articleDrill/civillaw.json`, 2026-10-13 수집)로 조문 번호 순서와 절 이름을 대조했다.
  민법 제1편 제5장 법률행위(제1절 총칙·제2절 의사표시·제3절 대리·제4절 무효와 취소·제5절 조건과 기한),
  제2편 물권(총칙·점유권·소유권[한계·취득·공동소유]·지상권·지역권·전세권·유치권·저당권),
  제3편 제2장 계약(제1절 총칙[성립·효력·해지, 해제]·매매[총칙·효력·환매]·교환·임대차)이 뼈대다.
- **기출의 실제 분포** — 400문항을 한 문항씩 읽어 어디에 앉는지 먼저 정한 뒤 절의 크기를 쟀다.

## 판정 규칙

1. 법령 편제가 갈라 놓은 자리는 그대로 따른다(편·장의 뼈대).
2. 법령이 말하지 않는 갈림은 기본서 **다수결**(여섯 곳 중 넷 이상, 경록은 장 판정에만 센다).
3. 다수결과 **실익**이 갈리면 실익 — 장 하나에 25문항이 넘으면 절로 확실히 나누고, 절 하나는 15문항
   안팎을 넘지 않게 한다(30을 넘으면 반드시 가른다). 기출이 0~1문항인 절은 이웃 절에 합친다.
4. 절 이름은 기본서나 법령에 실제로 있는 이름만 쓴다. 「종합」「기타」 칸은 두지 않는다.
5. 문항은 **발문을 먼저 믿는다.** 발문이 주제를 말하지 않으면 선지의 다수가 다루는 제도로, 그래도 갈리면
   정답 선지가 묻는 제도로 보낸다. 사례형은 쟁점이 되는 제도로 보낸다.

## 갈린 자리를 어떻게 정했나

1. **의사표시를 장으로** — 박문각만 법률행위 장 안에 둔다(5:1). 민법도 제5장 제2절로 따로 둔다.
2. **토지거래허가(유동적 무효)는 「무효와 취소」 장** — 여섯 곳 모두 민사특별법이 아니라 법률행위의 무효 아래다.
   이름은 위패스 「법률행위의 유동적 무효」를 줄여 「유동적 무효(토지거래허가)」.
3. **매매·교환·임대차를 장으로** — 다수결로는 「계약법 각론」 한 장이지만 그러면 48문항이 한 칸이다.
   에듀윌(장 넷)·위패스(매매·임대차 장)를 따랐다(실익). 교환은 4문항이지만 에듀윌이 장으로 두고 민법도
   절(제4절 교환)을 따로 둔다.
4. **계약법 총론은 한 장, 일곱 절** — 위패스만 장 넷으로 쪼갠다(5:1). 장은 다수결대로 두고 절로 확실히 갈랐다.
5. **「계약의 종류」 문항(5문항)은 계약법으로** — 옛 목차는 「권리의 변동」에 두었으나, 발문이 「계약의 유형과
   성질」을 묻고 여섯 곳 모두 계약법 총론 첫 절이다.
6. **계약금(해약금)은 매매로** — 민법 §565(해약금)는 매매 절(제3절 제1관 총칙)에 있고 에듀윌·위패스도
   「매매의 성립」 아래다. 옛 목차는 「계약해제」에 두었다.
7. **토지임차인의 지상물매수청구권은 임대차로** — 민법 §643(임차인의 갱신청구권, 매수청구권)은 임대차 절이다.
   옛 목차는 이름이 닮은 「지상권」에 두었다(4문항).
8. **양도담보는 가등기담보법으로** — 부동산 양도담보는 가등기담보법이 적용되고, 에듀윌이 이 법 제1절
   「비전형담보와 동법의 적용범위」에서 다룬다.
9. **1문항짜리 절은 두지 않았다** — 법률행위의 해석(오표시무해 1문항 → 착오로 인한 의사표시), 점유보호청구권
   (1 → 점유권의 효력), 저당권의 물상대위·일괄경매·제3취득자·공동저당(각 1 → 저당권 갈래), 주택 적용범위·
   임차권등기명령(각 1 → 대항력과 우선변제권), 상가 대항력(1 → 적용범위와 대항력), 집합건물 재건축(1 → 관리단).
