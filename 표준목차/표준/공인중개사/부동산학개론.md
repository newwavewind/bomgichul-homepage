## 편 — 셋이 크게 갈린다

| | 편 수 | 짜임 |
|---|---:|---|
| 박문각 | 3 | 총론 / 각론 / 감정평가론 — 그 아래는 **테마 40개** (장·절 없음) |
| 에듀윌 | 3 | 총론 / 각론 / 감정평가론 — 각론 아래 6장 |
| 해커스 | **8** | 총론 / 경제론 / 시장론 / 정책론 / 투자론 / 금융론 / 개발및관리론 / 감정평가론 |

**다수결은 3편(박문각·에듀윌)인데 규칙 2로 8편을 택한다.**
3편으로 묶으면 「각론」 한 칸에 **400문항 중 297문항**이 들어간다. 목차 구실을 못 한다.
해커스가 각론의 여섯 갈래를 각각 편으로 올린 것이 문항 분포와 맞물린다.

박문각의 테마 40개도 실은 같은 갈래다 — 테마 04~17이 경제·시장·정책, 18~29가 투자·금융,
30~34가 개발·관리다. 이름만 층이 다르고 **셋의 갈래는 같다.**

## 장·절

3사 중 **절까지 갖춘 것은 에듀윌·해커스** 둘이다(박문각은 테마라 절이 없다).
편을 해커스로 정했으므로 장·절도 해커스를 뼈대로 하고, 에듀윌이 더 잘게 나눈
자리는 규칙 2로 받는다.

따로 있고 감정평가에 관한 규칙상 독립한 방법이므로 세운다.
