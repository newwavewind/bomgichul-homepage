# 검증 — 39과목 10,460문항 · 찾은 버그와 고친 자리

2026-08-27 · 다섯 갈래 병렬 검증(앱 4 + 참조 끊김 교차검증) · 하위 에이전트 5

## 왜 빌드로는 못 잡았나

찾은 버그 대부분이 **빌드를 통과한다.** `undefined` 가 화면에 렌더되고,
목차 필터가 아무 문항도 못 잡고, 정렬표가 조용히 가나다순으로 떨어지는 종류다.
**「빌드 통과 = 무사」가 아니다** — 실제 렌더 식을 평가하고, 화면이 세는 방식 그대로
문항 수를 다시 세어야 드러난다.

## 치명 — 화면이 실제로 깨져 있던 것

### 1. 공무원 597문항이 「목차별」에서 사라져 있었다
지방세법 156 · 회계원리 168 · 회계학 273.
`unit_id` 를 새로 발급하면서 문항의 옛 `taxonomy_unit_id` 를 안 지웠는데,
`examMatchesFilter` 는 **양쪽에 id 가 있으면 id 로만 맞대고 편·절로 되돌아가지 않는다.**
죽은 id 를 든 문항은 어느 칸에도 안 걸린다. → 650문항에서 옛 id 를 마저 뗐다.

### 2. 주택관리사 4과목의 편·장 이름이 화면에 안 떴다
`curriculum.json` 을 다시 쓰면서 `label`·`shortLabel`·`style` 대신 `title` 만 넣었다.
화면은 `shortLabel` 을 읽는다 → 편 제목 `PART 1 undefined`, 장 제목 빈칸,
통계 도넛 전부 회색, 빈칸 정렬 「알 수 없음」 뭉치, 쉬운해설 대단원 「기타」.
→ 네 파일을 정상 스키마로 되돌렸다.

### 3. 부동산학개론 목차를 앱이 읽지도 않는 파일에 고쳤다
이 과목만 `data/subjects/realestate/curriculum.json` 을 읽는데
`data/realestate/curriculum.json` 을 고쳤다. 앱이 보던 목차는 「CHAPTER 01 (미분류)」 **한 칸**.
→ 8편 22장 51절을 앱이 읽는 파일로 옮겼다.

## 배치 자체가 틀렸던 것 — 사회복지사

「절 이름이 곧 주제」라 보고 절→편을 1:1 로 굳혔는데, **절 이름이 모호한 자리**에서 어긋났다.

- 인간행동 「이론과 실천」 33문항 중 25문항이 다른 편 주제였다.
  로저스 7·매슬로우 3이 1편에 묻혀, 정작 「인본주의이론」 장은 6문항뿐이었다.
- 지역사회복지론 「지역사회복지」 20문항 중 13, 실천론 「실천의 개념」 18문항 중 15,
  법제론 「총칙」 7문항 전부, 행정론 「평가」 14문항 중 6이 지문과 다른 자리였다.

→ 지문의 학자·법률·주제로 갈라 **66문항을 제자리로** 보냈다.
법제론 「OO법상」 지문의 장 이름 일치율이 **33% → 55%** 로 올랐다.

## 무사했던 것 (실제로 확인함)

- **문항 내용은 하나도 안 상했다** — 10,860문항에서 `category`·`subcategory`·
  `taxonomy_unit_id`·`textbook_order` 밖의 필드가 달라진 문항 **0건**, 문항 수·id 집합 그대로
- 개념카드 ↔ 기출은 `questionRefs`(연도+번호) 로 이어져 무사
- 오답노트·AI 노트는 기출 id 키라 무사
- `src/data/questions.json`(OX 지문 2,000개)은 import 하는 코드가 없는 죽은 데이터

## 남긴 것 — 판단이 필요하거나 이번 범위 밖

1. **학습 이어보기 저장 키.** 장 id 가 위치 기반(`p1-c03`)이라, 목차가 바뀌면
   같은 id 가 다른 장을 가리킨다(326장) 또는 사라진다(273장).
   이미 앱을 쓰던 사람의 이어보기 위치가 유실되거나 엉뚱한 장에 붙는다.
   목차를 고치는 한 피할 수 없고, 없애려면 **마이그레이션 코드**가 따로 필요하다.
2. **재생성 파이프라인.** `remap_categories.{mjs,py}`·`category_overrides.json` 이
   옛 분류를 들고 있다. 다시 돌리면 이번 개편이 통째로 되돌아간다 → **경고를 박아 두었다.**
3. **사회복지사 개념카드 원본.** `data/allinone/cards/*.json` 은 안 바뀌었다.
   `build_cards` 를 돌리면 되돌아간다.
4. **마인드맵의 오래된 불일치.** 중개사법 43·공법 12·세법 32·공시법 8 자리는
   **개편 이전부터** 안 맞았다(HEAD 에서도 같았다). 이번 작업과 무관해 손대지 않았다.
