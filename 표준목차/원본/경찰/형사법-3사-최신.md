# 경찰 「형사법」 — 3사 목차 (다시 봄, 2026-08-28)

앞 파일 `형사법-3사.md` 는 **해커스 갓대환 · 해커스 허정 · 느루 신광은** 을 「3사」라 적었다.
갓대환과 허정은 **같은 해커스경찰**이다. 두 곳을 세 곳으로 셈한 것이다.
이번에는 허정을 빼고 **박문각**을 찾아 넣어 진짜 세 곳으로 맞췄다.

세 곳 모두 권을 나눠 낸다. 세 갈래를 모두 받았다.
