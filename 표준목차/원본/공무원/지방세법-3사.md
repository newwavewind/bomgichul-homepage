## 갈린 자리 (현행 세 곳)

- **편은 만장일치** — 지방세기본법 → 지방세징수법 → 지방세법 → 지방세특례제한법. (부크크만 지방세법을 앞에 둔다)
- **지방세기본법의 장 순서가 갈린다**
  - 배움: 총칙 / 납세의무 / **부과** / **환급금과 담보** / **채권관계** / 납세자권리 / 불복 / 범칙 / 과세자료 / 보칙
  - 공단기: 총칙 / 납세의무 / **채권관계** / **부과** / **환급금과 담보** / 불복 / 납세자권리 / 과세자료·정보화 / 범칙 / 보칙
  - 시대에듀: 공단기와 같은 순서(채권관계가 부과보다 앞)
  - **법제처 지방세기본법은 배움과 같다** — 제1장 총칙 / 제2장 납세의무 / 제3장 부과 / 제4장 지방세환급금과 납세담보 / 제5장 지방세와 다른 채권의 관계 / 제6장 납세자의 권리 / 제7장 이의신청 및 심판청구 / 제8장 범칙행위 / 제9장 과세자료의 제출 및 관리 / 제10장 지방세 업무의 정보화 / 제11장 보칙
- **지방세법 편의 첫 세목이 갈린다** — 배움은 취득세, 공단기·시대에듀는 **재산세**. 다만 세 곳 다 재산세를 취득세 바로 옆(1~3번째)에 둔다. 법제처는 재산세가 제9장이다
- **지방세특례제한법의 장** — 배움 2장(총칙 및 보칙 / 감면), 공단기 1장(총칙 안에 통칙·보칙·감면), 시대에듀는 지방세법 편 안 12번 항목
- **지방세징수법 3장**(총칙/징수/체납처분)은 배움·공단기가 같다. 시대에듀만 총칙과 징수를 붙였다
