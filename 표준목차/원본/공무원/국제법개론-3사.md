## 해커스 — 패권 국제법 기본서 일반국제법

- **제1편 국제법 총론**
  - 제1장 서론 — 제1절 국제법의 의의 / 2 법적 성질 / 3 발달사
  - 제2장 국제법의 연원 — 1 총설 / 2 조약 / 3 국제관습법 / 4 법의 일반원칙 / 5 학설 및 판례 / 6 형평과 선 / 7 국제기구결의 / 8 연성법규론 / 9 국가의 일방행위 / 10 강행규범 / 11 대세적 의무 / 12 국제법 연원 상호관계
  - 제3장 조약법 — 1 총설 / 2 성립 / 3 유보 / 4 효력 / 5 해석 / 6 무효 / 7 정지 / 8 종료 / 9 개정 및 수정
  - 제4장 국제법과 국내법의 관계 — 1 총설 / 2 학설 / 3 관행 / 4 우리나라에서 국제법과 국내법 관계
  - 제5장 국제법의 주체 — 1 총설 / 2 국가 / 3 국제기구 / 4 개인 / 5 민족과 자결권
- **제2편 국가**
  - 제1장 승인 — 1 국가승인 / 2 정부승인 / 3 교전단체승인
  - 제2장 국가의 기본적 권리 및 의무 — 1 총설 / 2 주권 / 3 평등권 / 4 자위권 / 5 국내문제 불간섭의무
  - 제3장 국가관할권 및 면제 — 1 국가관할권 / 2 국가면제 / 3 국가행위이론
  - 제4장 국가책임 — 1 총설 / 2 위법행위책임 / 3 결과책임 / 4 국제기구의 국제위법행위에 대한 책임
  - 제5장 국가의 대외기관 — 1 외교사절 / 2 영사 / 3 군대 / 4 군함
  - 제6장 국가승계 — 1 총설 / 2 조약승계 / 3 주요 국가승계 사례
- **제3편 국제기구** — 제1장 국제연합(UN): 1 총설 / 2 총회 / 3 안전보장이사회 / 4 기타 주요기관 / 5 UN 전문기구 / 6 UN 평화유지활동(PKO) · 제2장 유럽연합(EU)
- **제4편 개인**
  - 제1장 국민 및 외국인 — 1 국민과 국적 / 2 외교적 보호 / 3 외국인 / 4 범죄인 인도
  - 제2장 국제인권법 — 1 총설 / 2 UN의 인권보호 / 3 국제인권규약 / 4 지역인권규약 / 5 국제난민법 / 6 국제형사재판소(ICC) / 7 기타 인권관련 다자 조약
- **제5편 국제법의 규율 대상**
  - 제1장 해양법 — 1 총설 / 2 내수 / 3 군도수역 / 4 영해 / 5 해협 / 6 접속수역 / 7 배타적 경제수역 / 8 대륙붕 / 9 공해 / 10 심해저 / 11 섬 / 12 해양분쟁해결제도 / 13 해양법협약의 기타 쟁점
  - 제2장 국제법의 객체 — 1 영토 / 2 영공 / 3 우주공간 / 4 극지
  - 제3장 국제환경법 — 1 의의 및 특성 / 2 발달과정 / 3 기본원칙 / 4 분야별 주요 국제 환경협약
- **제6편 국제분쟁해결 및 무력사용**

  - 제2장 전쟁과 평화에 관한 법 — 1 총설 / 2 무력사용의 제한 / 3 국제인도법 / 4 군축 / 5 국제테러리즘

## 갈린 자리 (현행 세 곳)

- **큰 흐름은 셋이 같다**: 총론(연원·조약법·국내법 관계) → 국가(승인·관할권·면제·책임·대외기관·승계) → 개인·인권 / 규율 대상(해양·영공·우주·환경) → 분쟁해결·무력사용 → 국제경제법
- **편을 세우는 곳은 해커스뿐**이다. 김중일(29장)과 정인섭(23장)은 편 없이 장만 늘어놓는다. 편 구조는 다수결이 서지 않는다
- **국제기구의 자리는 셋이 다 다르다** — 해커스 제3편(국가 뒤·개인 앞), 정인섭 제15장(해양·환경 뒤·개인 앞), 김중일 제24장(개인·규율대상 뒤). **다만 셋 다 분쟁해결·무력사용보다 앞에 둔다**
- **국제형사재판소(ICC)** — 해커스는 제4편 국제인권법 안(제6절), 김중일은 제28장(전쟁법 다음), 정인섭은 제19장 국제형사법(범죄인인도 다음). **해커스만 인권법 쪽이고 나머지 둘은 형사·전쟁 쪽**
- **범죄인 인도** — 해커스는 제4편 개인 안, 김중일은 제9~13장 관할권·면제 묶음 근처, 정인섭은 제18장(인권법 다음). 갈린다
- **국가승계** — 해커스 제2편 제6장, 김중일 제19장, 정인섭 제12장. 셋 다 「국가」 묶음의 끝자락이다
- **영토** — 해커스는 제5편 「국제법의 객체」 안, 정인섭은 제11장 「국가 영역」(국가 묶음), 김중일은 제18장 「영토의 취득」. 갈린다
