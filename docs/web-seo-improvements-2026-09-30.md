## SEO와 앱 유입

- 공개 URL·canonical·기존 sitemap/리다이렉트를 유지한다. 공개 문제와 해설을 클라이언트 전용이나 로그인 전용으로 옮기지 않았다.
- 개인 학습 도구와 내부 검색 결과는 `noindex, follow`다. 공개 시험·과목·회차·문제·개념은 색인 가능 상태를 유지한다.
- 홈페이지에 검색 목적을 설명하는 H1과 시험별 설명을 제공하고, 시험 허브와 문제의 앱 안내 동선을 연결한다.
- 앱스토어 클릭은 설치 완료가 아니다. GA 이벤트 `web_app_conversion`의 정의는 **스토어로 이동한 클릭**이다. 앱 코드를 건드리지 않으므로 설치/구매 완료를 검증하지 않는다.
- GA 설정이 활성화된 배포 환경에서 이벤트를 전송한다. 개인 메모 본문·계정 ID·검색어는 새 이벤트에 넣지 않는다. GA 관리 콘솔의 주요 이벤트 설정이나 Search Console 제출은 실행하지 않았다.
- 검색 순위나 실제 유입 증감은 배포 후 Search Console/GA로 측정해야 한다.

## 저장과 운영 범위

- 새 주간 보고서·계획·오답 이유·요약집은 **이 브라우저의 계정별 localStorage**다. 다른 기기·앱과 동기화하지 않으며, 저장소 삭제 시 사라진다. 기존 학습 이력을 소급하여 채우지 않는다.
- 비공개 개인 메모는 기존 서버 저장소를 사용한다. 공개 질문은 기존 메모·댓글에 읽을 수 있는 상태 접두어를 저장하여 DB 스키마 변경을 피했다.
- 운영자 검수 표시는 서버가 현재 관리자임을 확인한 검수 의견에만 표시한다. 작성자의 답변 채택과 운영자 검수는 구분한다. 기존 답변을 자동으로 검수 완료 처리하지 않았다.
- 현재 기록 연결 지점은 공통 문항 상세/트랙 학습 도구와 개념 회독이다. 별도의 과거 모의고사·랜덤 연습 결과를 소급 병합하지 않는다.
- 한국사/영어 등 해당 문제에 연결 개념이 없는 경우 억지로 링크를 만들지 않는다.

## 검증

- `scripts/verify-web-seo.mjs`: 14개 시험에서 홈→허브→과목→회차→문항→연결 개념의 HTTP 200, canonical, title, description, H1, robots, JSON-LD, 서버 HTML 해설·링크 검사.
- 변경 관련 회귀 테스트 22개 통과. 전체 기존 테스트 실행에서는 공무원 과목 수를 16개로 고정한 기존 검사 1개 실패(해당 데이터/검사 파일은 이번 작업에서 변경하지 않음).
- 새 파일 및 비공개 메모 편집기 ESLint 통과. 기존 파일에 있던 effect 내 상태 변경 lint 경고/오류는 별도 기존 부채로 남아 있다.
- 익명 REST 조회에서 question_notes 0건, HTTP 200 확인. 실제 로그인 계정으로 공개 글·댓글을 게시하거나 계정 메모를 변경하는 검증은 하지 않았다.
- 브라우저에서 시험 검색, 문항 채점, 오답 이유, 보고서 반영, 계획 저장·재진입을 확인했다.
- 공개 사이트 배포는 하지 않았다.

최종 확인: 14개 시험의 총 **64개 페이지** SEO 검증 통과. `npm run build` 최종 재실행은 타입 검사 및 752개 정적 페이지 생성까지 성공했다. 중간 Turbopack 폰트 오류는 재실행에서 재현되지 않았다. 별도 webpack 빌드는 기존 페이지의 허용되지 않는 named export(`CommunityWritePage`)로 실패했으며, 기본 빌드와 구분한다. 390px 모바일 화면에서 가로 넘침 없이 채점·오답 이유·sticky 다음 이동을 확인했다. 검증 결과 JSON과 화면은 `artifacts/web-review/`에 있다.
