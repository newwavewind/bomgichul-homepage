# 현재 무료 강의 교재 연결

공인중개사 311강(12,723쪽), 소방공무원 공채 ready 215강(5,913쪽), 공인중개사 6과목 통합 기본서(12,744쪽)를 2026-11-04 기출 중복 정리 최종 PDF로 연결한다. 각 R2 URL은 전체 SHA를 포함하는 immutable 경로다.

- `/real-estate/textbooks`: 개별311권과 통합6권.
- `/firefighter/textbooks`: 공채215권. 경채·준비중 교재를 만들거나 노출하지 않는다.
- 강의 목록의 교재 버튼은 첫3강 여부와 관계없이 로그인·구매 없이 연다. 강의 영상은 과목별 첫3강만 기존 웹 플레이어를 사용하고 이후 강의는 기존 앱 안내를 유지한다.
- 공유 교재 뷰어는 읽기/새창/저장을 제공한다. 같은 강의의 PDF SHA가 바뀌면 열린 뷰어도 새 문서를 사용한다.
- 현재532개 ID/SHA/원격URL은 검수 원장과 결합했다. 공인중개사317개 원격 검증은 기존 전체 GET SHA 근거를 승계하고, 소방215개는 새 경로에 업로드해 전체 GET SHA와4개 Origin HEAD/Range/CORS를 검증했다. 기존 객체·CORS는 변경하지 않았다.

검증은 배포 빌드, TypeScript, 교재/강의범위 테스트, 운영 HTTP payload 전수대조, 대표 브라우저 실제 열기로 구분한다. 브라우저 download 이벤트 대기가 타임아웃되어 UI 저장은 완료로 주장하지 않는다. 소방 스토어 링크의 기존 Android null 정책과 이를 반영하지 못한 기존 firefighter-lectures 테스트1개는 이번 교재 변경에서 수정하지 않았다.
